# РАСПИСАНИЕ

Файлы, перенесённые с Google Диска 18.11.2026: распределение нагрузки, учебные планы по годам набора, график учебного процесса, документы и HTML-расписания. Плюс исследование программы «Ректор-ВУЗ».

## Структура

- **Корень** — 94 файла из «Моего диска»: учебные планы (`*_дневное_*`, `*_заочное_*`), «График 2026-2027», «Нагрузка КИТ 26-27 по полугодиям.xls», три .doc и четыре HTML-расписания ЮФ.
- **`Untitled folder/`** — 7 файлов нагрузки из одноимённой папки на Диске.
- **`Исследование/Ректор-ВУЗ.md`** — какие данные вводятся в «Ректор-ВУЗ», в каком виде и как формируется расписание.
